# Northlane Consulting — Website

A 5-page responsive business website for Northlane Consulting, a fictional operations & growth strategy consultancy.

🔗 **Live site:** [northlane-consulting.netlify.app](https://northlane-consulting.netlify.app/) 

## ✨ Features

- 5 fully built pages — Home, About, Services, Work, Contact
- Custom design system with a consistent header, footer, and type scale across every page
- Interactive 3D tilt-on-hover card in the homepage hero
- Scroll-triggered reveal animations
- Fully responsive layout — tested at mobile, tablet, and desktop breakpoints
- Working contact form with client-side validation
- Accessible: visible keyboard focus states, semantic HTML, reduced-motion support
- Security headers configured for deployment (CSP, X-Frame-Options, Referrer-Policy)

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, CSS Grid & Flexbox, CSS 3D transforms)
- Vanilla JavaScript (no frameworks or build tools)
- Google Fonts (Fraunces, Inter)
- Deployed on Netlify

## 🚀 Running Locally

No build step required. Clone the repo and open `index.html` in a browser, or serve it with any static server, e.g.:

```
npx serve .
```
